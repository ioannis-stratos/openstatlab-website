
# OpenStatLab

### Free, Open-Source Statistical Software for Scientific Research

**OpenStatLab** is a free, open-source statistical analysis application developed by **Ioannis Stratos**.

Designed with clinical and scientific research in mind, OpenStatLab provides accessible statistical tools through a browser-based interface without requiring commercial software subscriptions.

**Website:** https://openstatlab.com

**License:** MIT License  
**Status:** Beta / Research software  
**Developer:** Ioannis Stratos (independent project)

---

## Key Features

- Free and open-source software
- Offline statistical analysis
- Browser-based interface
- Desktop applications for Windows, macOS and Linux
- No commercial subscription required
- Statistical methods for clinical and scientific research
- Statistical visualizations and graphical outputs
- Tools supporting statistical analysis and study planning

## Statistical Methods

OpenStatLab includes methods and tools for:

- Descriptive statistics
- Normality testing
- Parametric and nonparametric hypothesis tests
- Paired and independent group comparisons
- Analysis of variance (ANOVA)
- Correlation analysis
- Linear and logistic regression
- Survival analysis
- Statistical visualization
- Sample size and power analysis

Available methods and functionality may vary between software versions.

## Privacy and Offline Use

OpenStatLab is designed to perform statistical calculations locally.

The standalone HTML version can be used offline in a compatible browser.

The project does not require a cloud-based statistical analysis service.

Users remain responsible for protecting their data and complying with applicable institutional data protection policies.

## Development

OpenStatLab was independently developed by **Ioannis Stratos**, with assistance from generative artificial intelligence.

The project is not an official product of any university, hospital or commercial institution.

The goal is to make statistical analysis accessible to researchers, students and other interested users.

## Scientific Validation and Disclaimer

**OpenStatLab is currently beta research software.**

Statistical algorithms and outputs may not have undergone complete independent validation.

Users should verify important results using established statistical software, such as R, particularly before scientific publication.

OpenStatLab is provided for research and educational purposes and should not be used as the sole basis for clinical or other consequential decisions.
